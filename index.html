FEATURES

一个浏览器，装下你的全部日常

从多标签页到扩展生态，Neutron Browser 把 PC 浏览器该有的体验都打磨到位。

多标签页浏览

新建、切换、关闭、拖拽排序、固定、静音、复制标签页，多任务浏览游刃有余。

智能地址栏

自动识别网址、IP、本地路径与搜索关键词，前进 / 后退 / 刷新 / 主页，还支持鼠标侧键导航。

Edge 风格下载

彩色文件图标、来源域名、实时进度与速度；暂停 / 继续 / 取消、重新开始、复制链接，工具栏环形进度与完成徽章。

主题皮肤系统

7 种强调色 × 12 套主题皮肤（海洋 / 森林 / 星空 / 樱花……）× 明暗模式，三维正交自由组合，打造独一无二的浏览器。

扩展生态

安装 .crx / .zip 扩展包、从 Edge 扩展商店按链接或 ID 安装、加载已解压目录；Edge 风格扩展管理与二级详情界面。

书签与历史

书签栏快捷访问、文件夹整理、书签管理器；历史记录按日期分组、搜索、单条删除、一键清除，JSON 持久化存储。

窗口置顶

标题栏图钉按钮一键置顶 / 取消，置顶状态持久化，边看边写不再来回切换窗口。

自动更新

检测到新版本后应用内自动下载、静默安装并自动重启，Edge 式一键更新，永远用上最新版本。

完整快捷键

Chrome 风格快捷键：Ctrl+T 新标签页、Ctrl+L 聚焦地址栏、Ctrl+J 下载、Ctrl+, 设置……全部内置。

安全设计

contextIsolation + contextBridge 安全架构、neutron:// 内部协议、下载 / 权限 / 弹窗 / 崩溃全程处理。

安装说明

  1. 下载安装包点击上方按钮，下载 Neutron-Browser-Setup-1.8.2.exe。
  2. 运行安装向导可自定义安装目录，勾选创建桌面 / 开始菜单快捷方式。
  3. 开始使用启动 Neutron Browser，导入书签、选择主题，即刻畅游网络。
💡 小贴士

安装后可在「设置 → 关于」中一键「检查更新」，应用内自动下载并静默安装新版本。
